# Суть работы
В рамках практической работы был изучен и законспектирован материал по теме «Системы ввода-вывода и интерфейсы». Рассмотрены базовые понятия архитектуры интерфейсов, классификация способов передачи данных, принципы расчета скорости, а также схемы взаимодействия задатчика и исполнителя.
