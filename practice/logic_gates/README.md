## Суть работы
В рамках практической работы были выполнены задания по переводу логических схем в аналитические выражения (формулы) и обратному переводу формул в схемы из базовых логических элементов (И, ИЛИ, НЕ). 

## Выполненные задачи
*   Анализ готовых схем с белым фоном: определение логической функции и составление формулы.
*   Синтез схем: построение логических элементов на основе заданных математических выражений.
