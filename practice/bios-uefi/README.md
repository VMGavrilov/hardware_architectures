## Что внутри
Практическая работа по изучению интерфейса BIOS/UEFI на симуляторе Lenovo ThinkPad T14s Gen 5. В ходе работы были отработаны навыки навигации по меню, настройки порядка загрузки, управления безопасностью (Secure Boot, пароли) и периферией.
