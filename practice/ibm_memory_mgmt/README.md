# Суть работы
В рамках практической работы был изучен и законспектирован материал по теме «Управление памятью в ЭВМ». Рассмотрены принципы организации памяти, функции операционных систем по её управлению, а также механизмы работы виртуальной памяти.

# Выполненные задачи
Изучены иерархическая организация памяти и классификация запоминающих устройств.
Разобраны стратегии управления памятью (выборки, размещения, замещения).
Проанализированы виды организации реальной памяти (однопрограммная, мультипрограммная, с фиксированными и динамическими разделами).
Изучена концепция виртуальной памяти, включая страничную, сегментную и сегментно-страничную организацию.
