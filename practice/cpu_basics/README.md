# Суть работы
В рамках домашнего задания были изучены и законспектированы ключевые принципы работы центрального процессора. Рассмотрены теоретические основы построения вычислительных машин, структура базовых элементов и механизмы обработки данных на аппаратном уровне.

# Выполненные задачи
Изучен рабочий цикл процессора: этапы выборки, дешифрации и выполнения команд.
Разобраны принципы взаимодействия процессора с оперативной памятью через системную шину.
Проанализирован механизм обработки прерываний и работа со стеком.
Изучены элементы процессора: АЛУ, устройство управления, регистры, шины и их взаимодействие.
Рассмотрены базовые архитектуры систем команд (стековая, аккумуляторная, регистровая) и особенности процессора Intel 8086.
