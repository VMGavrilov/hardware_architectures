# Сравнение HDD и SSD, оперативная память

## Таблица: HDD vs SSD

| Параметр | HDD | SSD |
|---|---|---|
| **Принцип работы** | Запись и чтение данных на вращающиеся магнитные пластины с помощью механической головки | Хранение данных в энергонезависимой флеш-памяти (NAND) без движущихся частей |
| **Скорость чтения/записи (примерно)** | 100–200 МБ/с | 500–3500 МБ/с (SATA — до 550, NVMe — до 7000) |
| **Наличие движущихся частей** | Есть (шпиндель, магнитные головки) | Нет (полностью электронный) |
| **Устойчивость к ударам** | Низкая (при ударе головка может поцарапать пластину) | Высокая (нет механики, данные не пострадают при падении) |
| **Уровень шума** | Есть шум от вращения шпинделя и работы головок | Бесшумный |
| **Цена за 1 ТБ** | 2 500 – 4 000 ₽ (дешевле) | 6 000 – 12 000 ₽ (дороже) |
| **Срок службы / ограничения** | 5–10 лет; ограничен механическим износом, чувствителен к тряске | 5–10 лет; ограничен количеством циклов перезаписи (TBW), деградация ячеек памяти |
| **Пример использования** | Файловые серверы, архивы, видеонаблюдение, недорогие ПК для хранения больших объемов данных | Операционная система, программы, игры, ноутбуки, серверы с высокой нагрузкой |

---

## 1. DDR — это тип оперативной памяти, который передает данные в два раза быстрее обычного (на каждом такте).

## 2. DIMM — это сама планка оперативной памяти, которую ты вставляешь в компьютер.

## 3. Ранг (rank) — это группа чипов на планке памяти, которые включаются в работу одновременно.

## 4. CAS Latency (CL) — это задержка (в тактах), пока память «достанет» нужные данные, поэтому чем меньше число, тем лучше.

## 5. Тайминги — это набор таких задержек (набор цифр вроде 16-18-18-38), и чем они меньше, тем быстрее работает память.

## 6. Двухканальный режим — это когда две планки памяти работают вместе, чтобы быстрее передавать данные (как две полосы движения вместо одной).
