## Что внутри

Домашняя работа, посвященная выбору блока питания и системы охлаждения для ПК. В теоретической части разобраны типы БП, их характеристики, сертификаты 80 PLUS, типы охлаждения и принципы работы кулеров. В практической части произведен расчет мощности блока питания для игровой сборки и выполнено сравнение трех моделей кулеров для процессора Intel Core i5-13600K.
