## Что внутри

Комплексная задача: выбрать из трёх наборов комплектующих оптимальный ПК для игр 1440p и стриминга, с учётом ограничений корпуса, БП, линий PCIe и памяти. Всё решается на бумаге — без запуска ПК и без входа в BIOS.

## Краткий итог решения

- **Выбран набор A** (i5-13600K + B760 ATX + DDR5-6000 + RTX 4070): единственный, кто закрывает требование «второй NVMe + звуковая карта» (2× M.2 Key M, запас слотов PCIe).
- **B отсеян** — нет второго Key M (Key E только для Wi-Fi).
- **C отсеян** — только 1× M.2 и 1× PCIe x1, переходник не решает.
- **Ограничения набора A:** не хватает EPS 4-pin (у БП один EPS 8-pin) → турбо может быть ограничен; GPU 12VHPWR требует переходника 8-pin→12VHPWR; второй M.2 делит канал DMI с USB/SATA/сетью.
- По форм-фактору корпуса все три набора совместимы (ловушка задания).
